# shellhacks-2026
Wayfind is a AI-powered pathfinding assistant that helps users choose a route based on their preferences. 
It uses route information, personal preferences, and AI-powered reasoning to recommend routes to the user.

# Problem
Modern transportation tools always find the quickest route, but never accounts for which route is best based on the user's preferences such as they want minimal walking or don't mind a longer travel time.

# Solution
WayFind takes user input such as; their destination, arrival time, their preferences (travel time, walking distance, cost, etc.).
